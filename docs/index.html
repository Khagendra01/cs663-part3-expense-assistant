I built this with the Google Agent Development Kit and Gemini 2.5 Flash. I upload a receipt photo, the agent reads the store, date, items and total, and saves it. Then I can ask how much I spent, at one store or in total.

Status: this page first tries the live backend. If the live call fails, it shows the sample answer below and says so. No API key is in this page.
